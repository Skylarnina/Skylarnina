# The Magnificent 5 Days Bootcamp — website
Next.js 14 + Tailwind + Supabase. Pages: Home, About, Programme, Trainers, FAQ, Contact, Donate, Register (5 steps), Login, Dashboard, My Plan, Community, Members, Admin.
Setup: 1) create a Supabase project, 2) run `supabase/schema.sql` in the SQL editor, 3) set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`, 4) deploy. The account that signs up with the owner email in `app_settings` becomes admin automatically.
