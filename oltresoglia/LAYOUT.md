# OLTRESOGLIA layout tokens

Values used in Figma (Kehinde, 26 Oct) so every page stays consistent. CSS: `styles/layout.css`.

| Token | Value | Use |
|---|---|---|
| Page base | `#F5F3EE` | Light page background; also the off-white text colour on dark (replaces the old cool Porcelain `#EBF0F2`) |
| Box white | `#FFFFFF` | Light boxes |
| Box dark | `#0D0D0D` | Dark boxes and dark sections (replaces `#050505`) |
| Box dark 2 | `#141414` | Dark inner cards, a dark box sitting on dark |
| Yellow | `#F9BF58` | Brand yellow / Saffron (replaces `#EFC04D`) |
| Radius header | 28 px | Header / hero panels, pop-up frame |
| Radius box | 24 px | Content boxes |
| Radius card | 18 px | Inner cards |
| Inner padding | ~40 px (24 px mobile) | Inside boxes |
| Gap between boxes | 24–48 px | |
| Mobile inset | 16 px | Boxes stay 16 px from the screen edges |

Framer: set these as Color Styles (Page base, Box white, Box dark, Box dark 2, Yellow) and use the radius / padding values on every frame.
