# Conversion Portfolio

A conversion-focused single-page portfolio for a premium Framer/Webflow developer,
aimed at SaaS, agency and service-brand buyers.

- **`DESIGN.md`** — the full spec: wireframes section by section, the copy deck,
  layout and type system, per-section animation notes, Framer/Webflow
  implementation plan, and the performance budget.
- **`index.html`** — a working prototype of the spec. Self-contained: open it in a
  browser, no build step. GSAP + ScrollTrigger from a CDN, Google Fonts,
  zero image payload (project previews are drawn in CSS).

Sections: Hero → Selected Work (4 case studies) → Value/Edge → Process →
Services → Final CTA.

> The client names, case studies and metrics are sample content chosen to show the
> layout with realistically shaped copy. Replace them with verifiable results
> before publishing.
